# jlog

A command line tool to simplify the process of interstitial journalling.

## Features

- Simple CLI

## Installation

```bash
git clone https://github.com/greppetto/jlog
cd jlog
uv sync
uv run jlog --help
```

## Options and Flags

```bash
positional arguments:
    day             Day Attributes

options:
    -h, --help              show this help message and exit
    -l, --license           Show license information and exit
    -q, --quiet             Use quiet output
    -v, --verbose           Use verbose output
```
